# 🚀 AI Business Intelligence Platform

A professional AI-powered Business Intelligence application built using Python and Streamlit.

---

## Features

- CSV Upload
- Excel Upload
- PDF Upload
- Automatic Data Cleaning
- Interactive Dashboard
- KPI Cards
- Sales Analysis
- Customer Analytics
- Product Analytics
- Geographic Dashboard
- Prophet Forecasting
- XGBoost Prediction
- AI Business Insights
- PDF Report Generation
- Excel Export
- Responsive UI
- Dark Theme

---

## Technology

- Python
- Streamlit
- Plotly
- Pandas
- Scikit-learn
- XGBoost
- Prophet

---

## Installation

```bash
pip install -r requirements.txt
```

Run

```bash
streamlit run app.py
```
